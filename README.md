# MJU Workspace Releases

Repositori ini menyediakan installer dan metadata pembaruan MJU Workspace Desktop.

Unduh versi terbaru melalui halaman Releases. Data bisnis, akun, kredensial database, dan kode sumber privat tidak disimpan di repositori ini.

## Unduh aplikasi

Buka [rilis terbaru](https://github.com/mjuprinting/workspace-release/releases/latest) dan pilih installer pada bagian Assets. Berkas source code ZIP/TAR otomatis dari GitHub bukan installer aplikasi.

## Source dan pembaruan

Source proyek web/internal berada di repositori private [mjuprinting/mju-workspace](https://github.com/mjuprinting/mju-workspace) dan membutuhkan akun yang memiliki akses. Source pembungkus desktop perlu dikelola dari proyek desktop yang sesuai.

Perubahan kode dicatat di repositori source. Installer, checksum, dan metadata pembaruan yang telah dibangun serta diuji dipublikasikan melalui Releases repositori ini. Jangan menyimpan database, lampiran usaha, akun atau kredensial instalasi di repositori rilis.
